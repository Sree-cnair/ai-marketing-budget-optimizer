# AI Marketing Budget Optimizer & Performance Metrics Calculator

An independent portfolio project by Sreejitha Nair, focused on practical performance marketing and marketing analytics.

## Current tool: Paid Media Performance Calculator

A browser-based calculator for Meta Ads, Google Ads and LinkedIn Ads. Enter campaign delivery and funnel metrics to calculate:

- CPM, CTR and CPC
- Click-to-lead conversion rate and CPL
- MQL rate and cost per MQL
- MQL-to-SQL rate and cost per SQL
- CPA and ROAS
- Basic funnel diagnostic prompts to guide further investigation

## Run it

Open [index.html](./index.html) in a modern browser. No installation, build step, API key or advertising account connection is required.

## Metric formulas

| Metric | Formula |
|---|---|
| CPM | Spend / impressions × 1,000 |
| CTR | Clicks / impressions × 100 |
| CPC | Spend / clicks |
| Click-to-lead CVR | Leads / clicks × 100 |
| CPL | Spend / leads |
| MQL rate | MQLs / leads × 100 |
| Cost per MQL | Spend / MQLs |
| SQL rate | SQLs / MQLs × 100 |
| Cost per SQL | Spend / SQLs |
| CPA | Spend / conversions |
| ROAS | Attributed revenue / spend |

## Important notes

This is a portfolio learning tool, not a live advertising-platform integration. It uses user-entered data and does not transmit it to a server. Diagnostic thresholds are illustrative prompts, not universal benchmarks. Use consistent reporting dates, attribution windows and conversion definitions when comparing platforms.
